# Champion portraits

Square champion icons from Riot Games Data Dragon **16.20.1**.

Source: https://ddragon.leagueoflegends.com/cdn/dragontail-16.20.1.tgz
Documentation: https://developer.riotgames.com/docs/lol#data-dragon

Original filenames match each champion's `riotId`, including `MonkeyKing` (Wukong) and `JarvanIV` (Jarvan IV). The portraits are served locally; no Riot API key or runtime Riot request is needed. Riot Games retains ownership of its game assets.
